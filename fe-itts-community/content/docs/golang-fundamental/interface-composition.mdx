# Interface & Composition

Memahami interface dan composition pattern di Go untuk membuat kode yang flexible dan maintainable.

## Interface Basics

Interface di Go mendefinisikan behavior, bukan implementasi.

```go
type Writer interface {
    Write([]byte) (int, error)
}

type FileWriter struct {
    path string
}

func (fw FileWriter) Write(data []byte) (int, error) {
    // implementation
    return len(data), nil
}
```

## Composition over Inheritance

Go tidak mendukung inheritance, tapi mendukung composition.

```go
type Logger struct {
    writer Writer
}

func (l Logger) Log(message string) {
    l.writer.Write([]byte(message))
}
```

<Callout type="info">
Prefer composition over inheritance untuk membuat kode yang lebih flexible dan testable.
</Callout>
