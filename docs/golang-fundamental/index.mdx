## Struktur Pembelajaran

### 1. Dasar Golang

Kenalan dengan workspace Go, tipe data dasar, error handling, dan modul go test.

**Yang akan dipelajari:**
- Setup go workspaces + modul
- Tipe data dasar, pointer, dan struct
- Menulis unit test dan benchmarking sederhana

[Mulai belajar →](/docs/golang-fundamental/dasar-golang)

### 2. Pemrograman Konkuren

Pahami goroutine, channel, context, serta pattern worker pool.

**Yang akan dipelajari:**
- Goroutine & channel pattern
- Context cancellation + timeout
- Worker pool / fan-in fan-out

### 3. Membangun Service Mini

Gabungkan dengan HTTP/gRPC, logging, dan observability sederhana.

**Yang akan dipelajari:**
- REST vs gRPC skeleton
- Structured logging & instrumentation
- Deployment + profiling
