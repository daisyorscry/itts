# Struct & Method Receiver

Mendesain domain model dengan method yang ringkas.

## Konsep Dasar

### Definisi Struct

Pisahkan struct ke paket `internal/<domain>` agar tidak bocor lintas modul.

```go
package user

type Profile struct {
    ID       string
    Username string
    Email    string
}
```

### Method Receiver

Gunakan pointer receiver jika method memodifikasi state, value receiver untuk operasi read-only.

```go
// Value receiver - read-only
func (p Profile) GetDisplayName() string {
    return p.Username
}

// Pointer receiver - modifies state
func (p *Profile) UpdateEmail(newEmail string) {
    p.Email = newEmail
}
```

<Callout type="warning">
Hati-hati dengan pointer receiver! Gunakan hanya saat method perlu memodifikasi state struct.
</Callout>
