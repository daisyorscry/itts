# Goroutine & Channel

Memahami concurrent programming dengan goroutine dan channel di Go.

## Goroutine

Goroutine adalah lightweight thread yang dikelola oleh Go runtime.

```go
func main() {
    // Launch goroutine
    go func() {
        fmt.Println("Running in goroutine")
    }()

    // Wait for goroutine to finish
    time.Sleep(time.Second)
}
```

## Channel

Channel digunakan untuk komunikasi antar goroutine.

```go
func main() {
    ch := make(chan string)

    go func() {
        ch <- "Hello from goroutine"
    }()

    msg := <-ch
    fmt.Println(msg)
}
```

<Callout type="warning">
Selalu close channel setelah selesai digunakan untuk menghindari goroutine leak!
</Callout>

## Buffered Channel

```go
// Buffered channel with capacity 3
ch := make(chan int, 3)

ch <- 1
ch <- 2
ch <- 3
// No blocking until buffer is full
```
