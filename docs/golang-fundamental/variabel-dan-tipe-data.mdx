# Variabel & Tipe Data Dasar

Memahami deklarasi dengan short assignment, zero value, dan konversi tipe.

## Konsep Utama

### Short Assignment

Gunakan `:=` untuk deklarasi cepat di dalam blok fungsi, sedangkan deklarasi global tetap memakai `var`.

```go
func main() {
    // Short assignment
    name := "John Doe"
    age := 25

    // Var declaration
    var email string
    email = "john@example.com"
}
```

### Zero Value

Kenali zero value untuk setiap tipe agar tahu kapan field belum diisi:
- `string` → `""`  (string kosong)
- `int` → `0`
- `bool` → `false`
- pointer → `nil`

<Callout type="info">
Zero values sangat berguna untuk mendeteksi apakah sebuah variabel sudah diinisialisasi atau belum.
</Callout>

## Best Practices

Praktikkan shadowing dengan hati-hati: `total := total + inc` terlihat rapi tapi bisa menimpa variabel luar.
